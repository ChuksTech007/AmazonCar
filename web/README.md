# Amason Car Sales

Kenya car-import website for **Amason Car Sales**. Stock is priced in **KES**. Sales line **+254 722 906978**.

## Run

```bash
cd web
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## Stack

Vite + React + React Router + Tailwind v4.

Brand assets live in `public/logo.png` and `public/cars/`.
